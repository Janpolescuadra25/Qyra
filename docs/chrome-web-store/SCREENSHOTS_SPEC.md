# Chrome Web Store Screenshot Specifications
**Required Dimensions**: 1280x800 px (or 640x400 px)
**Format**: PNG or 24-bit JPEG (no alpha channel)
**Minimum Count**: 4 screenshots

## Required Store Listing Screens
1. **01-scan-flow.png** (Document Scan & Auto-OCR)
   - Screen: Popup showing a scanned bill or receipt with extracted fields (Vendor, Date, Amount, Due Date, Line Items).
   - Caption: Automated OCR extraction from invoices and receipts.

2. **02-mapping-flow.png** (Entity & Account Mapping)
   - Screen: Mapping interface showing matched QuickBooks Online vendor, expense account, and payment terms.
   - Caption: Intelligent category and vendor matching to your QuickBooks chart of accounts.

3. **03-sync-history.png** (Sync History & Status)
   - Screen: Transaction sync history table displaying recent synced bills, checks, and journal entries with status badges.
   - Caption: Real-time sync tracking and comprehensive audit logs.

4. **04-settings.png** (Settings & Organization Profile)
   - Screen: Extension settings showing connected QuickBooks Online company and preference toggles.
   - Caption: Secure OAuth connection and customizable workflow settings.

## Upload Instructions
1. Save the 4 PNG files directly to `docs/chrome-web-store/`.
2. Upload each file to the Chrome Developer Dashboard under Store Listing > Graphic Assets > Screenshots.
